КОНТУР.МАРКЕТ — ГОРЯЧИЕ КЛАВИШИ v2

F10 = Оплата без сдачи
F11 = Оплата картой

1 нажатие = 1 клик.
2 быстрых нажатия = двойной клик.
Каждое новое нажатие обрабатывается отдельно.

НАСТРОЙКА:
1. Запустить программу.
2. Нажать «Настроить F10» и кликнуть по «Оплата без сдачи».
3. Нажать «Настроить F11» и кликнуть по «Оплата картой».
4. Настройки сохраняются в config.json.

Для автономного EXE на Windows:
pip install pyinstaller
pyinstaller --onefile --windowed main.py

EXE появится в dist\main.exe.
